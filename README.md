# Hər Gün Ərəbcə

Ərəbcə öyrənmək üçün sadə veb tətbiq. Feillər, dialoqlar və testlər bölmələrindən ibarətdir.

## Bölmələr

- **Feillər** — 350 ərəbcə feil (keçmiş, indiki, əmr formaları və nümunə cümlələrlə)
- **Dialoqlar** — 300 gündəlik dialoq nümunəsi
- **Testlər** — 250 test/məşq sualı

## İstifadə

`index.html` faylını brauzerdə açmaq kifayətdir. Əlavə quraşdırma tələb olunmur.

GitHub Pages ilə yayımlamaq üçün: Settings → Pages → Branch seçib saxlayın, bir neçə dəqiqədən sonra tətbiq canlı linkdə görünəcək.

## Fayl strukturu

- `index.html` — əsas səhifə və stillər
- `app.js` — əsas məntiq (menyu, öyrənmə, test yoxlanışı)
- `verbs.js` — feillərin məlumat bazası
- `dialogues.js` — dialoqların məlumat bazası
- `tests.js` — test suallarının məlumat bazası

Öyrənilən məlumatlar brauzerin `localStorage`-ında saxlanılır.
